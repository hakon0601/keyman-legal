# Keyman legal pages

Public HTTPS hosting for App Store Connect Privacy Policy and Terms of Use.
Source of truth remains in the product repo (`docs/legal/`); this repo is the
public mirror so Apple and users can load the pages while the product repo
is private.

## Live URLs

After GitHub Pages is enabled (Settings → Pages → Deploy from branch `main` / root):

- https://hakon0601.github.io/keyman-legal/privacy-policy.html
- https://hakon0601.github.io/keyman-legal/terms-of-use.html

## Updating

Copy updated HTML from `keyman-public/docs/legal/` and push to `main`.
